# Routina Fit

運動訓練與計數。Routina 家族的成員之一，獨立安裝，manifest 只有一行 `VIBRATE`。

規則只有一條：**紀錄是執行的副產物，訓練中不打字。** 跑完課表直接看到摘要，按一下存檔就結束——
全程沒有輸入任何數字。

## 畫面

底部四個分頁：**今天**（本週練了幾天、開始訓練、今天做了什麼）、**課表**（建立與編輯）、
**動作**（動作庫）、**紀錄**（依日期分段的歷史）。執行、計數、編輯這些是任務不是地方，
一律全螢幕蓋上去、不顯示分頁列。

## 功能

- **執行課表**：一次一個動作，計次型給一個可加減的大數字（預設帶目標，做不完就按 `−` 改成實際做到的），
  計時型自己倒數、歸零自動進休息。休息時整頁換成綠色，手機放在一公尺外也分得出現在該動還是該喘。
  倒數最後三秒短嘟、歸零長嘟加震動。
- **計數**：附帶功能，不是主功能。主要入口在動作列的 ⋯ →「計數」，首頁最下面也有一行捷徑。
  **數字往上加，目標只是參考**——本來想做 20 下、做一做做了 40 下，畫面上就寫 40，
  不會還在講「還剩下」。目標可以留空，那就是純粹做一下按一下。
  大 `＋1` 之外有 `+5` `+10`，給「做完一組才記」用；`撤銷` 退得回上一步。
- **動作庫**：依部位分組、可收合，展開狀態記在本機。每個動作標**要用到的工具**
  （徒手／啞鈴／椅凳，可自己加），上面一排晶片可以依工具篩選——
  回答的是「我現在手邊有什麼就能做什麼」。計次或計時是動作本身的屬性。
- **課表**：一項 = 動作＋目標＋重量＋這一項做完休息幾秒。順序就是訓練順序。
- **重量**：每一項可填可不填。執行中那顆重量膠囊刻意做得比次數小很多——同一個畫面兩個加減，靠大小分主從。
- **紀錄**：課表與計數混在同一份清單，因為它們是同一個資料結構（`routineId == null` 就是計數）。
  沒做滿的項目在摘要裡用紅字標出來。
- **備份**：整包匯出／匯入 JSON，依 id 合併，重複匯入不會長出重複資料。

資料全部存在 App 私有目錄，沒有後端、沒有帳號、不連網。

## 內建的動作與課表

首次啟動會載入 24 個動作與兩張課表（`居家啞鈴 Day1` 13 項、`Day2` 11 項），
裝好就能直接開始練，不必先花時間建資料。

其中 23 個動作與兩張課表來自使用者原本的啞鈴訓練表（`開合跳 35(sec)`、`啞鈴後弓步 16` 這些數字
就是表格裡的值），第 24 個是 `伏地挺身`。**重量一律留空**——原始表格沒有這一欄，值該由使用者
第一次訓練時自己填。部位與工具的分類是依動作名稱推的，可以改。

內建動作之後才長出來的欄位（例如 0.2.0 的工具）會由 `FitRepository.migrateSeed` 一次性補齊，
只補使用者沒填過的，不覆蓋任何已有的值。

種子資料在 [`assets/seed_exercises.json`](app/src/main/assets/seed_exercises.json) 與
[`assets/seed_routines.json`](app/src/main/assets/seed_routines.json)。
使用者自己把動作或課表刪光就維持空的，不會再回填。

## 字體與顏色

兩條規則來自家族的視覺研究，都是裝置實測過的：

- **中文字重封頂 Medium(500)**。Android 14 以前的 zh-Hant 字體只宣告 weight 400，
  SemiBold 與 Bold 會觸發合成假粗，看起來是糊的。層級改用字級與顏色深淺做。
  字距 `0.sp`、行高 1.5×、`includeFontPadding = false`（不關中文會在行框裡偏下）。
  全部集中在 [`ui/theme/Type.kt`](app/src/main/java/com/routina/fit/ui/theme/Type.kt)。
- **砍顏色面積，不砍顏色數**。飽和填色一頁只留一個（執行畫面的主要按鈕），
  其餘用容器色；休息時整頁換底色，但透明度只有 8%（亮）／14%（暗）。

整套色階是從家族種子色 `#4B5699` **算出來的**，不是手挑幾個值：在 Oklch 裡固定色相與彩度、
只變明度（選 Oklch 不選 CIELAB，因為藍色系在 Lab 提亮會往紫偏，而家族色正好是靛藍），
見 [`ui/theme/Palette.kt`](app/src/main/java/com/routina/fit/ui/theme/Palette.kt)。
`ColorScheme` 的每一個角色都給值——只要漏掉一個，Material 就會拿內建的**紫色**基線來補，
分頁列與晶片就會冒出與家族無關的紫。

帶意思的顏色只有三個，各自只講一件事：**正在做**＝主色、**休息**＝綠、**沒做滿**＝錯誤紅。

## 為什麼沒有通知權限

休息倒數會響，但訓練時 App 本來就在前景、螢幕常亮（只有執行頁與計數頁掛
`FLAG_KEEP_SCREEN_ON`，離開就拆），所以倒數不需要跑在背景，也就不需要通知權限與前景服務。
代價是休息時不能切去滑別的 App；這是刻意的取捨。

倒數用牆上時間算（記下目標時刻，而不是每秒減一），所以 App 被切走再回來，數字還是對的。

## 家族

Fit 會出現在 [Routina](https://github.com/ImitatedSky/routina)（Hub）的家族目錄裡。
掛進家族只靠 manifest 的四個 meta-data，是字串層級的約定、不是程式碼依賴，
所以這個 repo 不引用 Hub 的任何 library。

對外開放的能力（`start_routine` / `start_counter`，讓 Routina Flow 可以定時開當天的課表）排在 v0.3。

## 建置

需要 JDK 17 與 Android SDK（`local.properties` 的 `sdk.dir`）。

```sh
./gradlew :app:assembleDebug
```

Release 在有完整簽章資訊時（根目錄 `keystore.properties` 或 CI 的 `KEYSTORE_*` 環境變數）
用正式簽章，否則沿用 debug 簽章。家族全體共用同一把 keystore，成員才能就地更新。

## 發版

`vX.Y.Z` 標籤會產出一個永久保留的 Release，附 `routina-fit-vX.Y.Z.apk`。
CI 會先擋下標籤與 `versionName` 不一致的發版。
